# TaskFlow

予定やタスクの総合管理ツール。

## 概要

本プロジェクトは、個人タスクや作業スケジュール、簡易予定を直感的に管理・俯瞰するためのシステムです。
一般閲覧者向けのWeb表示機能（カレンダー・ガントチャート）と、管理者向けの操作機能（Web管理画面およびデスクトップGUIアプリ）から構成されます。

## システム構成

* **Web側 (閲覧・簡易管理)**
  * **言語/環境**: PHP 8.1.34 (Webサーバー: Apache)
  * **データベース**: MySQL 8.0
* **デスクトップアプリ側 (管理・自動計画)**
  * **フレームワーク**: C++ / Qt 6
  * **対応OS**: Windows, macOS, Linux (クロスプラットフォーム対応)
  * **特徴**: オフライン利用対応
