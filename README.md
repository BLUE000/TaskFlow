# TaskFlow

予定やタスクの総合管理ツール。

本プロジェクトは、個人タスクや作業スケジュール、簡易予定を直感的に管理・俯瞰するためのハイブリッドシステムです。
一般閲覧者向けのWeb表示機能（カレンダー・ガントチャート）と、管理者向けの操作機能（Web管理画面およびデスクトップGUIアプリ）から構成され、さくらインターネット等のレンタルサーバー環境（MySQL）とローカルPC（SQLite 3）をセキュアに同期して動作します。

---

## 🚀 設置方法（サーバー契約から公開まで）

本システム（Web側）をインターネット上に設置して利用可能にするまでの全手順を解説します。

### 1. サーバーの選定
まずはWebサイトとデータベースを動かすためのサーバーを用意します。

#### ■ 無料サーバーの候補（まずは試してみたい場合）
*   **シン・フリースペース** (エックスサーバー提供)
    *   **特徴**: 国内の大手サーバー会社が提供する無料プラン。PHP 8.x と MySQL が利用可能。広告が表示されますが、安定しています。
*   **スターサーバーフリー** (ネットオウル提供)
    *   **特徴**: PHP/MySQL対応プランがあり、容量も個人利用には十分です。広告表示あり。
*   **InfinityFree** (海外ホスティング)
    *   **特徴**: 広告ありですが、MySQLデータベース数やディスク容量の制限が緩く、完全無料でPHP/MySQL環境を構築できます。

#### ■ 有料サーバーの候補（安定運用・広告なしで使いたい場合）
*   **さくらのレンタルサーバ (スタンダードプラン以上)**
    *   **特徴**: 月額500円程度から。非常に安定しており、PHP 8.1/8.2、MySQL 8.0が快適に動作します。
*   **ロリポップ！ (ライトプラン以上)**
    *   **特徴**: 月額220円程度からMySQLが使えます。操作画面が初心者向けで分かりやすく、低コストでスタートできます。
*   **エックスサーバー (Xserver - スタンダード)**
    *   **特徴**: 月額1,000円程度から。国内最速クラスの圧倒的な高速性と安定性を誇り、商用レベルの運用に最適です。

### 2. 設置手順

#### ステップ1: データベース (MySQL) の作成
1.  契約したサーバーの管理画面（コントロールパネル）にログインします。
2.  「データベース設定」または「MySQL設定」から、新しいデータベースを作成します。
3.  以下の情報をメモして控えておきます。
    *   **データベース名 (DB_NAME)**
    *   **ユーザー名 (DB_USER)**
    *   **パスワード (DB_PASS)**
    *   **接続ホスト名 (DB_HOST)**（※ `localhost` またはサーバー固有のホスト名）
    *   **ポート番号 (DB_PORT)**（通常は `3306`）

#### ステップ2: データベースの初期化
1.  サーバー管理画面から「phpMyAdmin」などのデータベース管理ツールを開きます。
2.  作成したデータベースを選択し、「インポート」または「SQL実行」画面を開きます。
3.  本プロジェクトの [database/schema.sql](file:///d:/prog/PHP/TaskFlow/database/schema.sql) の内容をコピー＆ペーストして実行し、テーブルを作成します。

#### ステップ3: 設定ファイルの編集
1.  [config/config.php](file:///d:/prog/PHP/TaskFlow/config/config.php) をテキストエディタで開きます。
2.  先ほどメモしたデータベース接続情報を書き換えます。
    ```php
    define('DB_HOST', 'あなたのDBホスト名');
    define('DB_PORT', '3306');
    define('DB_NAME', 'あなたのDB名');
    define('DB_USER', 'あなたのDBユーザー名');
    define('DB_PASS', 'あなたのDBパスワード');
    ```
3.  **TransCipherのセキュリティ設定と管理者パスワード**:
    *   `TRANSCIPHER_SECRET_KEY`: 暗号化に使用する秘密のキーです。推測されにくいランダムな文字列（英数字32文字以上を推奨）に変更してください。
    *   `TRANSCIPHER_API_URL` & `TRANSCIPHER_API_TOKEN`: データの暗号化を行うTransCipher APIの設定です。
        *   **トークン発行手順**:
            1. TransCipher管理画面（例: `https://streamers-tool.sakura.ne.jp/TransCipher/`）にブラウザでアクセスします。
            2. アカウントを作成し、ダッシュボードから新しい「APIトークン」を発行してコピーします。
            3. コピーしたトークンを `TRANSCIPHER_API_TOKEN` に、指定されたエンドポイントURLを `TRANSCIPHER_API_URL` に設定します。
    *   `ADMIN_PASSWORD_HASH`: 管理画面のログインパスワードです。デフォルトは `admin123` に設定されています。
        *   ※本番運用時は、管理画面ログイン後に「パスワード変更」メニューから強固なパスワードに変更してください。

#### ステップ4: サーバーへのファイル配置
セキュリティを高めるため、**推奨構成（公開・非公開領域の分離）**での配置を推奨します。

##### 【推奨】セキュアな配置方法
サーバーのWeb公開ディレクトリ（例: `www/` や `public_html/`）の外側にシステムファイルを置くことで、ソースコードの漏洩を防ぎます。
*   **公開ディレクトリ（`www/` や `public_html/`）直下**:
    *   [public/](file:///d:/prog/PHP/TaskFlow/public/) フォルダの中身（`index.php`, `admin.php`, `css/`, `js/` など）をすべてアップロードします。
*   **公開ディレクトリの1つ上の階層**:
    *   `config/`, `src/`, `templates/`, `data/` フォルダをフォルダごとアップロードします。

##### 【簡易】一括配置方法（同一フォルダに置く場合）
サーバーの仕様で公開ディレクトリ以下にしか置けない場合は、プロジェクトを丸ごとアップロードし、`.htaccess` 等を利用してシステムディレクトリへのアクセスを禁止してください。
1.  プロジェクトフォルダ（`public`, `config`, `src`, `templates` などが入ったフォルダ全体）を公開ディレクトリにアップロードします。
2.  公開ディレクトリ直下の `.htaccess` ファイルに以下の記述を追加し、システムフォルダへの直接アクセスを遮断します。
    ```apache
    RedirectMatch 403 ^/(config|src|templates|database|data)/
    ```

## 🛠 使い方

### 1. 一般閲覧画面（カレンダー＆ガントチャート）
設置したURL（例: `https://example.com/`）にブラウザでアクセスします。
*   **カレンダー表示**: 月間および週間の予定を日曜日開始で表示します。
    *   予定のカテゴリごとに時間が表示されるかどうかが自動で切り替わります（設定による）。
    *   時間枠（午前・午後など）の合計作業時間が、許容作業時間の上限を超えた場合は警告色で強調表示され、過負荷をひと目で検知できます。
*   **ガントチャート表示**: 期間予定やタスクのタイムラインが表示され、進捗や先行タスクの依存関係（矢印）が可視化されます。
*   **カテゴリフィルター**: 画面上のカテゴリチップをクリックしてリアルタイムに表示を絞り込めます（トグルの開閉も可能）。

### 2. 管理画面での操作
画面右上の「ログイン」リンク（または `https://example.com/admin.php` に直接アクセス）からログインします。
*   **初期パスワード**: `admin123` (※ログイン後、ダッシュボード下部から必ず変更してください)
*   **主な機能**:
    *   **予定の追加・編集・削除**:
        *   最初はタイトル入力だけの「簡易予定」として登録し、後から日付や進捗を設定することで「期間予定」や「個人タスク」にシームレスに変化させられます。
    *   **やることメモ（日付未定）**:
        *   日付が決まっていないメモ（`type = 'memo'`）を登録・管理し、日付が決まったら「予定へ移行」ボタンで簡単にカレンダーへ配置できます。
    *   **繰り返し予定（同月内限定）**:
        *   期間予定を「毎日」「毎週同じ曜日」「平日のみ」でコピー生成できます。不注意による予定の無限増殖を防ぐため、コピーは「その月の月末まで」に制限されます。
    *   **先行タスクの設定**:
        *   タスクの依存関係を設定し、ガントチャート上に矢印を描画します。
    *   **Discord通知連携**:
        *   Discord Webhook URLを設定しておくことで、タスクの登録・変更時に自動でDiscordへ通知を飛ばせます。

### 3. デスクトップアプリ（C++ / Qt 6）との同期
ローカル環境で動作する C++ / Qt 6 デスクトップアプリを用いることで、オフライン時でも SQLite 3 データベースを介してタスク管理が可能です。
1.  デスクトップアプリの設定画面で、Web APIのURL（`https://example.com/sync.php`）、および `config.php` に設定した `TRANSCIPHER_SECRET_KEY` を入力します。
2.  オンライン時に「同期」を実行すると、ローカルとサーバーのデータが双方向にマージされます。
3.  万が一、ローカルとWebサーバーの双方で同じ予定が同時に変更されていた場合は「競合解決ダイアログ」が表示され、どちらのデータを残すかを選択できます。

## 🔌 外部ツール連携（予定取得API）

本システムのデータを外部ツールや外部システムと連携させたい場合、一般公開用の予定取得API（`public/schedules.php`）を利用できます。認証なしでGETリクエストにより予定を取得可能です。

### API エンドポイント
```
GET https://[あなたの設置ドメイン]/schedules.php
```

### クエリパラメータ
| パラメータ名 | 型 | 必須 | 説明 |
| :--- | :--- | :---: | :--- |
| `category` | 文字列 | ◯ | 取得対象のカテゴリ名（例: `work`, `private`） |
| `start_date` | 文字列 | ◯ | 取得開始日。 `YYYY-MM-DD` 形式（例: `2026-07-01`） |
| `days` | 整数 | ◯ | 取得する期間の日数（1以上の整数） |

### レスポンス
JSON 形式で該当期間の予定一覧が返却されます。
> [!IMPORTANT]
> **データの暗号化について**
> サーバー側の復号負荷を避けるため、予定タイトル（`title`）や詳細（`description`）などの暗号化されたフィールドは、**暗号化されたBase64文字列のまま返却されます。** 呼び出し側の外部ツールにて、共通鍵（`TRANSCIPHER_SECRET_KEY`）を用いて復号を行ってください。
